# linghaoyi 个人画廊

基于 GitHub Pages 的图片收藏夹，用于替代本地 EhViewer，方便随时随地在线查看。

## 访问地址

[https://linghaoyi0318.github.io/linghaoyi0318/gallery.html](https://linghaoyi0318.github.io/linghaoyi0318/gallery.html)

## 说明

- 图片来自本地备份
- 使用 albums.json 预加载
- 支持收藏、搜索、随机翻页、进度保存
